用途與資料

協助已有院內登入及病歷調閱權限的使用者，取得目前北榮病人的資料，在瀏覽器轉換為 FHIR R4 並下載。另提供原始 HTML 與急診摘要 PDF 下載，以及與已配對雲端懷爾抓抓的同病人急診、門診整合。工具不取代院方授權、調閱稽核或正式病歷。

依操作可能處理姓名、病歷號、完整或遮蔽的身分識別碼、生日、性別、就診、診斷、SOAP、用藥、醫囑、檢驗與檢查、生命徵象、原始 HTML 及急診摘要 PDF。這些資料用於確認同一病人、取得病歷、轉換 FHIR、下載或配對整合。工作分頁 URL、來源主機與病人情境用於來源核對及工作路由，不用於追蹤一般瀏覽歷史或一般鍵盤、滑鼠活動。

院內請求沿用使用者既有瀏覽器登入工作階段，可能附帶該來源的認證 cookie。沒有 cookies API 權限不代表請求不使用 cookie。本版不提供 NIIS 預防接種查詢，也不要求使用者設定 NIIS token 或病歷上傳後端。

院內查詢與調閱稽核

使用者啟動獨立下載或配對整合後，工具可能操作受支援的 HIS、qemr 與 ERS 頁面。配對門診流程可用姓名查詢，並以生日及其他身分資料核對病人。姓名含無法辨識的字時，可能使用部分姓名搜尋；無法唯一確認時，交由使用者在 HIS 核對並選定病人，再按「繼續抓取」重新核對及接續。

獨立下載及符合身分核對條件的門診流程，在 HIS 顯示調閱視窗時，可自動選擇並送出「醫療需要」。工具等待院內正常調閱稽核完成後才取得病歷；無法確認病人或控制項時停止或等待人工處理。調閱理由與操作可能由院方記錄，依院方的稽核及保存規則處理。使用者須確認本次操作符合其院內權限與實際醫療用途。

處理與傳送對象

  • 院內：向支援來源請求已授權資料；來源服務有自己的稽核及保存規則。
  • 本機下載：FHIR JSON 與原始 HTML ZIP 存到使用者下載位置，原始資料可能包含急診摘要 PDF。RAW、HTML 與 PDF 不去識別化，可能保留完整敏感資料。 FHIR 去識別化為下載 Bundle 的選用設定，不保證匿名，也不套用到配對的急診、門診資料交付。原始頁面可能保留所選期間以外的索引或同次就醫資料。
  • 已配對的雲端懷爾抓抓：未設定配對值時，預設使用雲端商店版 ID hhfoejpppfbkadcjifgfmfpdhikicmgf；使用者可修改或解除配對。急診啟動時，向配對擴充功能傳遞經核對的身分識別碼、生日及本次工作資訊。門診補抓時，接收對端的姓名、遮蔽身分識別碼及可用的生日、性別等核對資料，再向對端交付同病人的門診、報告與工作狀態。門診內容與報告可能分階段交付。傳輸檢查配對 ID、訊息協定與本次工作憑證；不是對任意擴充功能開放病歷。對端收到資料後的處理依雲端懷爾抓抓隱私權政策辦理，不能宣稱所有資料都不離開裝置。
  • 手動 MediPrisma：本版只依使用者操作開啟網站，不自動傳送病歷或匯入 Bundle。若使用者另在網站手動上傳或操作，依該網站政策處理。

本版不提供舊版的病歷後端上傳或自動匯入 MediPrisma 網站功能。這不撤回舊版已送出的資料，也不影響院內來源或配對對端依各自政策處理已取得的資料。

本機儲存、保存與刪除

Chrome 的 storage.local 保存配對 ID、本機去識別化金鑰、目前工作狀態與最多 20 筆歷史摘要；介面顯示最近 5 筆。工作狀態及摘要可能含病歷號、來源、錯誤、時間、檔名及下載交付狀態，不能稱為匿名資料，也沒有按天自動到期機制。下載 ID 與檔名表示下載已啟動，不保證作業系統已完整保存。

取得範圍、門診版與去識別化選項存於 storage.sync，可能隨使用者的 Chrome 同步設定傳送。storage.session 保存門診工作識別，避免背景工作重啟後沿用舊工作；重啟後需重新啟動。配對流程中的身分核對、接續資訊與病歷結果暫存於記憶體；完成確認、取消、逾時、解除配對或背景工作結束時，依工作流程釋放，不作為完整病歷資料庫持久保存。

新版背景工作啟動時，刪除舊版留在 local 與 sync 的 NIIS token，不讀取或遷移其值，並清除已淘汰的後端網址、API key 與上傳模式設定。Chrome 儲存不是本工具另行提供的加密保管箱，請保護裝置、Chrome 使用者設定檔與下載目錄。

可在「進階設定」清空雲端擴充功能 ID 並儲存，以解除配對並使原配對工作失效；明確儲存的空值會維持解除配對，不會回復預設 ID。也可在 Chrome 停用擴充功能，以停止後續讀取。取消或解除配對不能撤回已啟動的下載、已交付對端的資料或已送出的院內調閱紀錄。

解除安裝、停用或關閉擴充功能，不會刪除既有下載檔、系統與瀏覽器備份、院內稽核紀錄或對端已收到的資料。下載檔案由使用者依院方與裝置管理規範保存或刪除。來源及對端資料的查閱、更正或刪除，須依相應管理者流程處理。

支援請求不得附未授權病歷、cookie、token、金鑰或 RAW 檔案。

資料用途與聯絡方式

資料僅用於本政策所述的病歷取得、FHIR 轉換、本機下載與明確配對功能。除經核准的用途外，不將使用者資料販售或轉移給第三方；不基於與產品單一用途無關的目的使用或轉移資料；不將資料用於信用評等或貸款。
